## 为什么需要此变更

当前项目中没有可供 MCP（Model Context Protocol）客户端调用的服务。为了验证并打通 MCP 服务端开发流程，并提供一个最小可用的 Go 语言示例，我们需要一个能够执行"两数相加"的 MCP 服务。它既是一个可用的工具，也是后续在本仓库中扩展更多 Go 版 MCP 服务的参考模板。

## 变更内容

- 新增一个 Go 模块，构建独立的 MCP 服务端可执行文件。
- 注册一个名为 `add` 的 MCP 工具，接收两个数值参数 `a` 与 `b`，返回它们的和。
- 采用 stdio（标准输入输出）作为传输协议，便于被 MCP 客户端（如 Claude Code）直接拉起。
- 对非法输入（缺参、非数值等）返回清晰的错误响应而非让进程崩溃。
- 提供一份最小的客户端注册示例，说明如何在 MCP 客户端配置中引用本服务。

## 能力（Capabilities）

### 新增能力
- `mcp-add`：一个基于 Go 的 MCP 服务端能力，对外暴露 `add` 工具，实现两数相加并返回结果。

## 影响范围

- **新增代码**：仓库根目录下的 Go 工程（`go.mod`、`main.go` 等）。
- **新增依赖**：引入一个 Go 版 MCP SDK（例如 `github.com/mark3labs/mcp-go`），并写入 `go.mod`。
- **工具链要求**：本地需具备 Go 1.21+ 以完成编译与运行。
- **客户端集成**：使用者需将编译产物注册到 MCP 客户端配置（如 `.mcp.json` 或 Claude Code 的 MCP 设置）中，才能调用 `add` 工具。
- **无破坏性变更**：纯新增，不影响任何既有代码或配置。
